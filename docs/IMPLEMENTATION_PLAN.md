# 实施结构与工作包

以可观察的报销业务链路组织实现：先建立数据/恢复基础，再接草稿与材料、Agent与审核，最后完成提交和外围管理。所有功能属于同一产品和代码库，不拆独立展示台或通用Agent平台。

## 主要里程碑

1. 基础可运行：锁依赖、PG迁移、标准错误、持久图恢复和生成契约。
2. 申报可填写：五入口、独立人工总额、主体/账户、自动审批获取、费用与人工材料归属。
3. 材料可处理：逐份识别、角色/金额/日期事实、字段建议保护与受控人工确认。
4. 主链路闭环：确定规则、审核修正、报告失效、最终冻结提交及模拟排期。
5. 外围业务齐备：管理案件、任务/审计、本地台账与短问卷反馈。
6. 运行可复核：测试、源码导读、运行说明和真实模型评估分层记录。

## 完成定义

源码、迁移、锁依赖、生成契约、配置示例、前端页面及测试同时交付。核心负例不放行、越权拒绝、人工字段保护、旧报告拒绝和模拟创建幂等有行为验证；外部真实服务、未定义政策和未覆盖真实票面单独说明。

每包的具体行为、模块和验收见链接SPEC；共同规则只在产品/业务/技术/API基线定义，避免工作包各自发明制度。测试证据见[测试说明](TESTING.md)与[模型评估](MODEL_EVALUATION.md)。
